Работа с виртуальной машиной VirtualBox на Ubuntu, которая велась на
Shell. В данном проекте, я разработал систему автоматического мониторинга дискового пространства и архивации файлов в среде Ubuntu.
при превышении заданного порога (20%) скрипт автоматически архивирует N старейших файлов в .tar.gz,
удаляет их из рабочей директории и записывает событие в журнал с временной меткой.
Для кроссплатформенной поддержки реализован аналог на PowerShell;
ключевые сценарии покрыты тест-скриптами.
