# Disk Space Monitor & Log Archiver

Кроссплатформенный скрипт мониторинга дискового пространства и автоматической архивации логов. Реализован в рамках лабораторной работы по дисциплине «Архитектура данных» на виртуальной машине Ubuntu (VirtualBox), с портом на Windows PowerShell.

## Что делает скрипт

1. Вычисляет, какой процент диска занимает директория с логами (`LOG_DIR`).
2. Если занятое место превышает заданный порог (по умолчанию 20%):
   - находит `M` самых старых файлов в директории логов;
   - упаковывает их в архив с временной меткой в имени (`.tar.gz` на Linux, `.zip` на Windows) и кладёт в `BACKUP_DIR`;
   - удаляет заархивированные файлы из рабочей директории;
   - записывает событие в журнал `archive.log` (дата, имя архива, сколько файлов удалено, процент заполнения).
3. Если файлов в директории логов стало меньше нужного количества, скрипт восстанавливает недостающие из последнего созданного архива.

## Структура проекта

| Файл | Описание |
|---|---|
| `v_main_script.sh` | Финальная версия скрипта для Linux/Bash — мониторинг, архивация и восстановление логов. Пути и пороги настраиваются через переменные окружения `LOG_DIR`, `BACKUP_DIR`, `THRESHOLD`, `M` |
| `main_script.ps1` | Аналог для Windows PowerShell с той же логикой: мониторинг, архивация через `Compress-Archive` и восстановление через `Expand-Archive` |
| `v_test_main_script.sh` | Тестовый сценарий для Bash-версии: создаёт тестовые файлы, проверяет срабатывание архивации при превышении порога, ведение журнала и восстановление после удаления файлов |
| `test_main_scirpt.ps1` | Тестовый сценарий для PowerShell-версии: аналогичные проверки архивации, удаления старых файлов и восстановления |

## Запуск

### Linux / Bash

```bash
LOG_DIR=~/log BACKUP_DIR=~/backup THRESHOLD=20 M=3 bash v_main_script.sh
```

### Windows / PowerShell

```powershell
.\main_script.ps1 -LogDir "$env:USERPROFILE\log" -BackupDir "$env:USERPROFILE\backup" -Threshold 20 -M 3
```

## Тестирование

```bash
bash v_test_main_script.sh
```

```powershell
.\test_main_scirpt.ps1
```

Тесты создают файлы-заглушки в директории логов, запускают основной скрипт и проверяют:
- создание архива при превышении порога заполнения;
- удаление заархивированных файлов из рабочей директории;
- ведение журнала `archive.log`;
- восстановление файлов из последнего архива при их нехватке.

## Стек

- **Bash** + GNU coreutils (`du`, `df`, `tar`, `bc`)
- **PowerShell** (`Compress-Archive`, `Expand-Archive`, `Get-PSDrive`)
